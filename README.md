# 🚀 Trishul CRM

A modern **Full Stack Customer Relationship Management (CRM)** application built using **React, FastAPI, PostgreSQL (Supabase), SQLAlchemy, Tailwind CSS, and JWT Authentication**.

Trishul CRM helps businesses manage leads, customers, employees, tasks, reports, and business insights from one dashboard.

# ⚙ Installation

## Clone Repository

```bash
git clone https://github.com/Archie345/Trishul-CRM.git
```

## Backend

```bash
cd backend

python -m venv .venv

.venv\Scripts\activate

pip install -r requirements.txt

uvicorn app.main:app --reload
```

## Frontend

```bash
cd frontend

npm install

npm run dev
```
